# 🏢 i-tem: Optimización de Margen de Ganancia

**Descripción:**
Proyecto de análisis de datos para **i-tem**, cadena de retail especializada en electrónicos y accesorios, con el objetivo de **maximizar el margen de ganancia** mediante la identificación de productos y sucursales con mayor rentabilidad. Se analizan datos de ventas, costos y desempeño por sucursal para proponer acciones concretas de mejora.

**Enfoque:**
- Análisis de **margen por producto** (precio de venta vs. costo unitario).
- Evaluación de **rentabilidad por sucursal** (ingresos vs. costos).
- Detección de **tendencias estacionales** en ventas y costos.
